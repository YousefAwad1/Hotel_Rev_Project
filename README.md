# Hotel_Rev_Project
In this project I built a dashboard telling a story to answer these questions about a hotel chain's revenue:
1. Is hotel revenue growing?
2. Should we increase parking lot sizes?
3. What trends can we see in the data?

While answering these questions I:
1. Built a database from raw data with SQL.
2. Analyzed and retrieved data with SQL.
3. Connected Power BI to the database.
4. Visualized data in Power BI.
